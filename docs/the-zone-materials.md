# Material names in The Zone Blender template

The custom map template of [The Zone](https://store.steampowered.com/app/3491280/) defines these material names. The game replaces a material with this name by its own texture at load time. The list has 382 names, read from the template on 2026-09-11. The names are the folder names of the free PBR texture set that the template uses, with the prefix `z_`.

Regenerate the list with Blender in background mode. Run this in the game folder:

```
blender -b custom_map_blender_template/template.blend --python-expr "import bpy; print('\n'.join(sorted(m.name for m in bpy.data.materials)))"
```
